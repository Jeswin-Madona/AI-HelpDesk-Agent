===================================================================
TOPIC: Printer Connected But Not Printing & Print Spooler Errors
CATEGORY: Printer
===================================================================
Symptoms:
Documents sent to printer sit in queue indefinitely, printer status shows 'Offline' or 'User Intervention Required'.

Possible Causes:
- Windows Print Spooler service (spoolsv.exe) hung or crashed
- Stuck spool files (.SPL / .SHD) locked in system folder
- 'Use Printer Offline' option enabled in printer queue menu

Diagnostic Steps & Resolution:
1. Reset Windows Print Spooler Service & Clear Spool Queue:
   - Open Services (services.msc) -> Find Print Spooler -> Right-click -> Stop.
   - Open File Explorer: Navigate to C:\Windows\System32\spool\PRINTERS and delete all files.
   - In Services window, right-click Print Spooler -> Click Start.
2. Disable Offline Mode:
   - Open Settings -> Printers & Scanners -> Click Printer -> Open Print Queue.
   - Under Printer menu, uncheck 'Use Printer Offline' and 'Pause Printing'.
3. Run Windows Printer Troubleshooter in Settings.


===================================================================
TOPIC: Printer Not Detected or Not Found by Computer
CATEGORY: Printer
===================================================================
Symptoms:
Clicking 'Add Device' in Printers & Scanners yields no detected hardware.

Diagnostic Steps & Resolution:
1. Power cycle printer: Unplug power cord for 30 seconds, reconnect, and power back on.
2. Verify Wi-Fi network: Ensure both computer and printer are connected to the exact same Wi-Fi SSID.
3. Add printer manually using printer static IP address.
4. Download full feature driver package from HP/Epson/Canon support site.


===================================================================
TOPIC: Poor Print Quality (Faded Text, White Streaks, Smudges)
CATEGORY: Printer
===================================================================
Symptoms:
Horizontal white lines across printed text, distorted colors, toner powder rubbing off paper.

Diagnostic Steps & Resolution:
1. Run Printhead Cleaning Utility (Inkjet Printers):
   - Open Printer Properties -> Maintenance tab -> Run Head Cleaning cycle.
2. Re-distribute Toner Powder (Laser Printers):
   - Remove laser toner cartridge and gently shake side-to-side before re-inserting.
