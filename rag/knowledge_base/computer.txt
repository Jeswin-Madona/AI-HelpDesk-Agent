===================================================================
TOPIC: Laptop Running Slow & System Performance Optimization
CATEGORY: Computer
===================================================================
Symptoms:
Computer takes minutes to boot up, apps open sluggishly, cursor stutters or displays spinning loading icon.

Possible Causes:
- Too many startup applications running automatically at boot
- High memory (RAM) usage causing pagefile disk thrashing
- Fragmented mechanical hard drive (HDD) or low disk space
- Accumulated temporary files and system updates junk

Diagnostic Steps & Resolution:
1. Disable Unnecessary Startup Programs:
   - Open Task Manager (Ctrl+Shift+Esc) -> Click Startup Apps.
   - Right-click non-essential programs (launchers, updaters) and click Disable.
2. Clean Temporary Files:
   - Press Win+R, type temp and delete all files.
   - Press Win+R, type %temp% and delete all files.
   - Run Disk Cleanup (cleanmgr.exe), select system files, and clear update cleanup cache.
3. Hardware Upgrade Recommendation:
   - Upgrade from an HDD to a Solid State Drive (SSD) for up to 10x faster boot times.
   - Ensure system has at least 8 GB or 16 GB RAM.


===================================================================
TOPIC: High CPU Usage and High Memory RAM Usage
CATEGORY: Computer
===================================================================
Symptoms:
Task Manager shows CPU or RAM usage above 90%, fan spins continuously at full speed, system stutters.

Possible Causes:
- Runaway background process (wsappx, svchost, browser memory leaks)
- Excessive web browser tabs and extensions
- Malware cryptomining in background

Diagnostic Steps & Resolution:
1. End Resource-Intensive Processes:
   - Open Task Manager -> Processes tab -> Sort descending by CPU/Memory.
   - End task for unresponsive high-consuming apps.
2. Fix Windows Update Service:
   - Open Services (services.msc) -> Find Windows Update -> Restart.
   - Run System Repair: Open CMD as Admin, run sfc /scannow and DISM /Online /Cleanup-Image /RestoreHealth.
3. Turn on Browser Memory Saver Mode in Google Chrome.


===================================================================
TOPIC: Computer Overheating & Random Shutdowns
CATEGORY: Computer
===================================================================
Symptoms:
Laptop feels extremely hot, sudden abrupt power off without blue screen during heavy tasks, fan noise loud.

Possible Causes:
- Dust accumulation blocking heatsink fins and exhaust grilles
- Dried out CPU/GPU thermal paste
- Using laptop on soft surfaces (beds, blankets) blocking air intake

Diagnostic Steps & Resolution:
1. Elevate laptop on a hard flat surface or use a cooling pad.
2. Use compressed air to blow out dust from ventilation grilles.
3. Change Power Plan to Balanced and set Maximum Processor State to 95% in Power Options.


===================================================================
TOPIC: Computer Freezing & Hard Lockups
CATEGORY: Computer
===================================================================
Symptoms:
Screen freezes completely, mouse cursor stuck, keyboard Caps Lock light unresponsive.

Diagnostic Steps & Resolution:
1. Restart Graphics Driver: Press Win + Ctrl + Shift + B (screen flickers and driver reloads).
2. Test RAM: Press Win+R, type mdsched.exe and restart to test physical RAM modules for corruption.
3. Test Hard Drive: Open CMD as Admin, run chkdsk C: /f /r.


===================================================================
TOPIC: Storage Space Almost Full (Low Disk Space)
CATEGORY: Computer
===================================================================
Symptoms:
Red bar on C: Drive in File Explorer, error warning 'Low Disk Space', unable to download updates.

Diagnostic Steps & Resolution:
1. Open Settings -> System -> Storage -> Enable Storage Sense.
2. Click Temporary Files -> Delete Previous Windows Installation (Windows.old) and Delivery Optimization files.
3. Run command prompt as Admin and type: powercfg /hibernate off to disable hibernation file and free several Gigabytes equal to installed RAM.
